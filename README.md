# Lesslie Newbigin — Portfolio Website (Cinematic Edition)

All files flat — no folders. Upload everything at once, same as before.

## How to publish (GitHub Pages)

1. Repo name must be **exactly**: `lesslie-newbigin.github.io`
2. Unzip this file, select every file inside (Ctrl+A), drag them all into
   **Add file → Upload files** on your repo page → **Commit changes**
3. **Settings → Pages** → Source: `main` branch, `/ (root)` folder → **Save**
4. Live in 1–2 minutes at `https://lesslie-newbigin.github.io`

## What's new in this version

- Custom eased smooth-scroll (no external library) — glides instead of
  jumping, falls back to normal scroll on touch and reduced-motion.
- Split-text hero animation — name animates in letter-by-letter, accessible
  label preserved for screen readers.
- Scroll progress bar across the top of every page.
- Blur-to-focus section reveals instead of flat opacity fades.
- Context-aware cursor labels on the main hero buttons.
